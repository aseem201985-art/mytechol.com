الكود النظيف: 12 قاعدة تجعل مراجعة الكود أسرع مرتين

قواعد عملية مستخلصة من مراجعة آلاف الأسطر: التسمية، حدود الدوال، التعليقات المفيدة، وهيكلة الـ Modules.

أأحمد
· 2025-01-22 · 12 دقيقة قراءة · متوسط
{ }

الكود النظيف ليس كوداً «جميلاً»؛ هو كود أرخص في الصيانة. كل قاعدة هنا اختبرتها في مراجعات حقيقية، وكل واحدة منها توفّر وقتاً يمكن قياسه.

1. التسمية: أهم قرار في السطر

الاسم الجيد يجعل التعليق غير ضروري. الاسم السيئ يجعل الكود لغزاً حتى لك بعد شهرين.

// ❌
const d = 86400;
function proc(x, y) { /* ... */ }

// ✅
const SECONDS_PER_DAY = 86_400;
function calculateShippingCost(orderTotal: number, country: string): number { /* ... */ }
  • الاسم يصف ماذا لا كيف: activeUsers لا filteredArray2.
  • الدالة تبدأ بفعل: fetch, validate, format.
  • Boolean يبدأ بـ is/has/can: isExpired.
  • لا اختصارات غامضة: usrMgr ← userManager.

2. حجم الدوال: قاعدة الشاشة الواحدة

إذا احتجت التمرير لقراءة دالة، فهي طويلة. الهدف: أقل من 30 سطراً، ومستوى تجريد واحد فقط.

// ❌ كل شيء في دالة واحدة
async function createOrder(userId, items) {
  // تحقق… حساب… خصم… دفع… بريد… سجل
}

// ✅ كل خطوة باسمها
async function createOrder(userId: string, items: Item[]): Promise<Order> {
  const user = await getVerifiedUser(userId);
  const priced = applyPricing(items, user);
  const payment = await charge(priced, user);

  await Promise.all([
    sendReceipt(user, payment),
    audit.log("order.created", { userId, total: priced.total }),
  ]);

  return buildOrder(user, priced, payment);
}
قاعدة عملية: إن احتجت تعليقاً لشرح ماذا يفعل قسمٌ من الكود، فاستخرج ذلك القسم إلى دالة باسم ذلك التعليق.

3. التعليقات: لماذا لا ماذا

// ❌ يكرر الكود
// أضف 1 إلى i
i++;

// ✅ يشرح السبب
// نبدأ من 1 لأن الفهرس 0 محجوز لرأس الجدول في الملف المستورد
let i = 1;

// ✅ يحذّر من فخ غير واضح
// لا تستخدم .sort() هنا — تُعدّل الأصل وتكسر ترتيب القائمة في الواجهة
const sorted = [...items].sort(byDate);

4. هيكلة الوحدات

الملف الجيد يمثّل مفهوماً واحداً. إذا لم تستطع تسميته بجملة واحدة بلا «و»، فهو ملفان مدموجان.

المجلدالمسؤولية
auth/تسجيل الدخول، التوكن، حماية المسارات
orders/التسعير، المستودع، الخدمة
shared/الأخطاء والأدوات المشتركة

اتجاه التبعية دائماً نحو الداخل: الوحدات لا تعرف عن بعضها إلا عبر واجهات صريحة. هذا يجعل الاختبار ممكناً دون تشغيل قاعدة بيانات.

5. قائمة مراجعة سريعة

#السؤال
1هل يفهم الاسم ماذا يمثّل بلا قراءة تنفيذه؟
2هل الدالة أقل من 30 سطراً؟
3هل يوجد أكثر من مستوى تجريد واحد؟
4هل فيه تعليق يكرر الكود (احذفه)؟
5هل تتعامل مع ثلاث حالات: النجاح، الفشل، الحدود؟
6هل يمكن اختبارها بلا شبكة أو قاعدة بيانات؟
الخطوة التالية: اختر أطول دالة في مشروعك اليوم، واستخرج منها جزءاً واحداً إلى دالة مسماة. عمل 10 دقائق، أثره يبقى أشهراً.
