System Design Interview: كيف تفكّر أمام المهندس؟

خطة 45 دقيقة لحل أي سؤال تصميم نظام: فهم المتطلبات، الحسابات التقريبية، API، قاعدة البيانات، التخزين المؤقت، والتوسع.

مفريق MyTechol
· 2025-11-14 · 14 دقيقة قراءة · متقدم
SD

مقابلات System Design لا تختبر معرفتك بالتقنيات، بل طريقة تفكيرك في التعامل مع المجهول. هذا الإطار يساعدك على عدم الضياع.

1. وضّح المتطلبات

اسأل عن: عدد المستخدمين، أنواع القراءة/الكتابة، الأوقات الحرجة، والقيود المالية. لا تفترض.

2. الحسابات التقريبية

مستخدمون نشطون: 1M/day
طلبات/يوم: 10M → ~116 req/s peak × 10 = ~1.2k req/s
حجم المنشور: 1 KB → 10 GB/day

3. API البسيط

ابدأ بواجهة REST صغيرة. لا تُدخل GraphQL أو gRPC إلا إذا كان السؤال يتطلبهما.

4. قاعدة البيانات والتخزين

اختر SQL للبيانات المنظمة، و NoSQL للمرونة العالية. استخدم Cache للقراءات المتكررة.

5. التوسع والموثوقية

  • Load balancer أمام الخوادم.
  • CDN للملفات الثابتة.
  • Replication و Sharding حسب الحاجة.
