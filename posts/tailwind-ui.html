تصميم واجهات عربية جميلة مع Tailwind CSS و RTL

دليل شامل لضبط RTL، الخطوط العربية، والمسافات المنطقية (logical properties) لبناء واجهة متوازنة بصرياً.

ععاصم محمد
· 2025-01-15 · 10 دقائق قراءة · متوسط
UI

بناء واجهة عربية لا يعني «قلب كل شيء». يعني استخدام خصائص منطقية تفهم الاتجاه بدلاً من قيم فيزيائية ثابتة. الفرق يظهر مباشرة في الصيانة.

تهيئة RTL

<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head>
    <link href="https://fonts.googleapis.com/css2?family=Cairo:wght@400;600;700;800&display=swap" rel="stylesheet">
  </head>
  <body class="font-arabic">
// tailwind.config.js
export default {
  theme: {
    extend: {
      fontFamily: {
        arabic: ['Cairo', 'system-ui', 'sans-serif'],
        mono: ['JetBrains Mono', 'monospace'],
      },
    },
  },
};

dir="rtl" وحده يجعل المتصفح يعكس النصوص والجداول والقوائم تلقائياً. لكنه لا يعكس margin-left أو left.

الخصائص المنطقية

margin-leftmargin-inline-startms-4

<!-- ❌ ينكسر عند تبديل الاتجاه -->
<div class="ml-4 text-left"><span class="absolute left-2">🔍</span></div>

<!-- ✅ يعمل في العربية والإنجليزية -->
<div class="ms-4 text-start"><span class="absolute start-2">🔍</span></div>

الخطوط العربية: قواعد عملية

  • لا تستخدم خطاً لاتينياً للعربية — التشكيل والوصل يظهران مكسورين.
  • حجم أكبر بـ 1–2px: الحروف العربية أقصر ارتفاعاً عند نفس الحجم.
  • ارتفاع سطر 1.75–1.9: التشكيل يحتاج مساحة رأسية، وإلا يتداخل.
  • وزنان فقط كافيان: 400 و 700. كل وزن إضافي = طلب شبكة.
@layer base {
  html[lang="ar"] body {
    font-family: 'Cairo', system-ui, sans-serif;
    line-height: 1.8;
    letter-spacing: 0;        /* لا تستخدم letter-spacing مع العربية */
    font-size: 16px;
  }

  html[lang="ar"] h1,
  html[lang="ar"] h2,
  html[lang="ar"] h3 {
    line-height: 1.35;
    font-weight: 800;
  }
}
تنبيه مهم: letter-spacing يفصل الحروف العربية عن وصلاتها ويجعل النص غير مقروء. تجنّبه تماماً في النصوص العربية.

الإيقاع الطباعي

في العربية، السطر الطويل جداً متعب أكثر من الإنجليزية لأن العين تنتقل من اليمين بلا مرساة يسرى. استخدم max-w-prose لتحديد عرض مقروء مريح (حوالي 65 حرفاً).

مكوّنات جاهزة

<!-- زر أساسي -->
<button class="inline-flex items-center gap-2 rounded-full bg-violet-600
               px-6 py-3 font-bold text-white transition
               hover:bg-violet-500 active:scale-95">
  ابدأ الآن
</button>

<!-- حقل بحث -->
<div class="relative">
  <input class="w-full rounded-full border border-white/10 bg-white/5
                py-3 ps-11 pe-4 text-sm outline-none
                focus:border-cyan-400 focus:ring-4 focus:ring-cyan-400/10"
         placeholder="ابحث…">
  <span class="absolute start-4 top-1/2 -translate-y-1/2 text-slate-500">🔍</span>
</div>

<!-- بطاقة -->
<article class="rounded-2xl border border-white/10 bg-white/5 p-6
                transition hover:-translate-y-1 hover:border-white/25">
  <h3 class="text-lg font-bold">عنوان البطاقة</h3>
  <p class="mt-2 text-sm leading-relaxed text-slate-400">وصف قصير.</p>
</article>

لاحظ ps-11 و start-4: نفس المكوّن يعمل في العربية والإنجليزية دون أي شرط على الاتجاه.

أخطاء شائعة

  1. قلب الأيقونات يدوياً: أسهم التنقّل تُقلب بـ rtl:rotate-180، أما الشعارات فلا تُقلب.
  2. الأرقام مختلطة: اضبط font-variant-numeric إن احتجت أرقاماً موحّدة.
  3. كود مضمّن: يحتاج dir="ltr" صريحاً وإلا يُقلب.
  4. النصوص اللاتينية داخل جملة عربية: ضعها في <bdi>.
  5. نسيان الاختبار: بدّل dir إلى ltr وتأكد أن كل شيء سليم.
الخطوة التالية: في DevTools بدّل dir="rtl" إلى ltr. كل عنصر ينكسر هو عنصر يستخدم خصائص فيزيائية ويحتاج إصلاحاً.
