الأدوات التي تصنع فرقاً حقيقياً

كل أداة هنا استخدمتها فعلياً في مشاريع حقيقية. مع كل واحدة: لماذا هي مفيدة، بديلها المجاني، وأهم إعداداتها.

VS Code

code.visualstudio.com

المحرّر الأكثر انتشاراً. دليل إعداد كامل: الإضافات الأساسية، اختصارات تسرّع التنقّل، وحفظ الإعدادات في Git.

مجانيEditorDX
🐳

Docker

docker.com

بيئة تطوير مطابقة للإنتاج. نتعلّم Dockerfile نظيف، تعدد الطبقات، و docker compose لبيئة كاملة بأمر واحد.

طبعة مجانيةContainersDeploy
🗄️

DBeaver

dbeaver.io

عميل SQL عالمي يدعم PostgreSQL و MySQL و SQLite وأكثر. مجاني ومفتوح المصدر مع محرّر ERD.

مفتوح المصدرSQLDatabase
🧠

Ollama

ollama.com

تشغيل نماذج LLM محلياً على جهازك. خصوصية كاملة، بلا تكلفة API، ومناسب للتجربة والتعلّم.

مجانيLLMLocal
🖥️

tmux

github.com/tmux

جلسات طرفية لا تنقطع عند إغلاق الاتصال. أساسي للعمل على السيرفرات وتقسيم الشاشة بسرعة.

مفتوح المصدرTerminalCLI
🎨

Figma

figma.com

تصميم الواجهات والتعاون عليها قبل كتابة الكود. يدعم RTL والخطوط العربية بشكل جيد.

طبعة مجانيةUIDesign
🔀

Git + GitHub CLI

cli.github.com

إدارة الفروع والـ PRs من الطرفية. سكربتات تنشئ فرعاً وتفتح Pull Request بأمر واحد.

مجانيGitWorkflow
✧

ChatGPT / Claude

chat.openai.com · claude.ai

مساعدان يوميان للمراجعة والتوليد. القيمة الحقيقية في صياغة الأمر، لا في الأداة نفسها.

مدفوع جزئياًAssistantAI

Uptime Kuma

github.com/louislam/uptime-kuma

مراقبة المواقع والخدمات بديلاً مجانياً عن SaaS. تنبيهات على تيليجرام وتقارير حالة.
