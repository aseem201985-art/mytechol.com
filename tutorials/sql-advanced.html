SQL المتقدم: Window Functions، CTEs، وتحسين الأداء

تخطّى SELECT البسيط: استخدم CTEs، Window Functions، الفهارس، EXPLAIN ANALYZE، واستعلامات قابلة للصيانة.

بعد أن تعرّفت على SELECT و JOIN، حان وقت بناء استعلامات قابلة للصيانة والقياس. هذا الدرس يُركّز على الأنماط التي تُفرّق بين استعلام بطيء وآخر سريع.

CTEs: الاستعلامات المسمّاة

WITH monthly_revenue AS (
  SELECT DATE_TRUNC('month', created_at) AS month, SUM(amount) AS revenue
  FROM orders
  GROUP BY 1
)
SELECT month, revenue,
       LAG(revenue) OVER (ORDER BY month) AS prev,
       (revenue - LAG(revenue) OVER (ORDER BY month)) / NULLIF(LAG(revenue) OVER (ORDER BY month), 0) * 100 AS growth_pct
FROM monthly_revenue;

Window Functions

SELECT user_id, login_at,
       ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY login_at) AS nth
FROM logins;

الفهارس وكيف تختارها

الفهرس مثل فهرس الكتاب. فائدته أكبر في الأعمدة التي تُستخدم كثيراً في WHERE و JOIN، وصغيرة نسبياً.

CREATE INDEX idx_orders_user_created
ON orders(user_id, created_at DESC);

أنماط شائعة

  • تجنّب SELECT * في الإنتاج.
  • لا تضع فهارس على كل عمود؛ التحديثات تصبح بطيئة.
  • استخدم LIMIT مع استعلامات الاختبار.
