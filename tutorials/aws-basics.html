AWS للمطورين: EC2، S3، RDS، وLambda في مشروع واحد

غمض المفاهيم السحابية بمثال عملي: رفع ملفات، تشغيل خادم، قاعدة بيانات، ودوال serverless.

AWS

السحابة تبدو معقّدة بسبب المصطلحات الكثيرة. سنبني مشروعاً صغيراً يستخدم أهم خدمات AWS لنفهم كيف تتكامل.

EC2: الخوادم الافتراضية

EC2 يعطيك خادماً افتراضياً تتحكم فيه. ابدأ بـ t3.micro للتجربة، واستخدم Security Groups للتحكم بالمنافذ.

S3: التخزين

aws s3 cp file.zip s3://my-bucket/uploads/
aws s3 ls s3://my-bucket/uploads/

RDS: قواعد البيانات

RDS تُدير النسخ الاحتياطي والتحديثات والمراقبة عنك. اختر PostgreSQL أو MySQL حسب تطبيقك.

Lambda: دون خادم

مع Lambda تكتب دالة وتترك AWS تدير البنية. مثالية للمعالجة المؤقتة أو Webhooks.

مشروع: رفع ومعالجة ملفات

المستخدم يرفع ملفاً إلى S3 → يُشغّل حدث Lambda → تُقرأ البيانات وتُخزّن في RDS. هذا النمط شائع جداً في التطبيقات السحابية.
