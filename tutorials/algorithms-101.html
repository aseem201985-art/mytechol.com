الخوارزميات للطلاب: من Big-O إلى الشجرة الثنائية بأمثلة بصرية

مسار مبسّط لمن يبدأ من الصفر: كيف تقيس التعقيد الزمني وتختار البنية المناسبة قبل أن تكتب سطراً واحداً.

ععاصم محمد
· 2024-12-27 · 16 دقيقة قراءة · مبتدئ
O(n)

الخوارزميات ليست مادة للحفظ. هي طريقة للإجابة عن سؤال واحد: «هل سيبقى برنامجي سريعاً عندما تصبح البيانات كبيرة؟» هذا المقال يشرح الأساسيات بأمثلة وأرقام حقيقية.

Big-O بلغة بسيطة

Big-O لا يقيس الثواني — يقيس كيف ينمو الوقت مع نمو البيانات.

البحث: الخطي مقابل الثنائي

def linear_search(items: list, target) -> int:
    # O(n) — يعمل على أي قائمة، مرتّبة أو لا
    for i, v in enumerate(items):
        if v == target:
            return i
    return -1


def binary_search(items: list, target) -> int:
    # O(log n) — يتطلب قائمة مرتّبة
    lo, hi = 0, len(items) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if items[mid] == target:
            return mid
        if items[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

على مليون عنصر: البحث الخطي قد يحتاج مليون مقارنة، والثنائي 20 فقط. لكن الثنائي يشترط الترتيب — والترتيب نفسه يكلّف O(n log n). لذلك: إذا كنت ستبحث مرة واحدة فقط، الخطي أفضل؛ وإذا كنت ستبحث مراراً، رتّب أولاً.

الشجرة الثنائية للبحث (BST)

class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None


def insert(root, value):
    if root is None:
        return Node(value)
    if value < root.value:
        root.left = insert(root.left, value)
    elif value > root.value:
        root.right = insert(root.right, value)
    return root            # القيم المكررة تُتجاهل


def inorder(node) -> list:
    # تعيد القيم مرتّبة تصاعدياً — هذا هو سرّ الشجرة
    if node is None:
        return []
    return inorder(node.left) + [node.value] + inorder(node.right)


root = None
for v in [50, 30, 70, 20, 40, 60, 80]:
    root = insert(root, v)

print(inorder(root))
# [20, 30, 40, 50, 60, 70, 80]

لاحظ الترتيب: كل قيمة يسرى أصغر، وكل يمنى أكبر. هذا يسمح بالبحث في O(log n) — طالما أن الشجرة متوازنة. لو أدخلت قيماً مرتّبة تصاعدياً، تصبح الشجرة خطاً مستقيماً وتتحوّل كل العمليات إلى O(n). لهذا تستخدم المكتبات أشجاراً متوازنة ذاتياً (AVL/Red-Black).

تمارين (ابدأ بالأسهل)

  1. O(n): اكتب دالة تعيد أكبر عنصرين في قائمة بمرور واحد فقط.
  2. Hash: اكتب دالة تكتشف أول عنصر مكرر في قائمة — فكّر في O(n).
  3. O(log n): عدّل البحث الثنائي ليعيد موضع الإدراج إن لم يجد القيمة.
  4. Tree: اكتب دالة تعيد ارتفاع الشجرة، ثم دالة تتحقق من توازنها.
  5. تحدٍّ: اوجد العنصر الوحيد غير المكرر في قائمة كل عناصرها مكررة مرتين.
الخطوة التالية: خذ مليون رقم عشوائي، وقس زمن البحث الخطي مقابل الثنائي بعد الترتيب باستخدام time.perf_counter(). رؤية الأرقام بنفسك تثبّت الفهم أكثر من قراءة عشر مقالات.
