HTML و CSS من الصفر: ابنِ صفحتك الأولى في ساعة

لا تحتاج خبرة سابقة. في نهاية هذا الدرس ستكون قد كتبت صفحة كاملة تعمل على الحاسوب والجوال، وتفهم كل سطر كتبته.

كل صفحة ويب رأيتها اليوم — من محرك بحث إلى تطبيق بنكي — هي في النهاية ملف HTML يعطي البنية، وملف CSS يعطي الشكل. تعلّم هذين الشيئين ليس اختيارياً: هو الأساس الذي تقف عليه كل مكتبة وأداة ستأتي بعدها.

الفكرة التي يجب أن تخرج بها الآن: HTML هيكل، CSS مظهر، JavaScript سلوك. اخلط بينها وستتعب لاحقاً.

1. أدوات لا تحتاج شيئاً

لا تحتاج تثبيت أي برنامج. تحتاج أمرين فقط:

  • محرّر نص — VS Code (مجاني) أو أي محرّر تفضّله.
  • متصفح — Chrome أو Firefox، وستستخدم فيه أدوات المطوّر (F12).

أنشئ مجلد المشروع، وبداخله ملفين باسمين محددين تماماً:

my-first-page/
├── index.html
└── style.css

الاسم index.html ليس عشوائياً: هو الملف الذي يفتحه المتصفح تلقائياً عند زيارة المجلد.

2. بنية ملف HTML

كل ملف HTML يبدأ بنفس الهيكل. اكتبه يدوياً مرتين أو ثلاثاً حتى يصبح تلقائياً:

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحتي الأولى</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1>مرحباً بالعالم</h1>
</body>
</html>

ما يهم حقاً في هذه الأسطر:

lang="ar"   → يخبر المتصفح أن المحتوى عربي
dir="rtl"   → يجعل اتجاه الصفحة من اليمين لليسار
charset     → يمنع ظهور رموز غريبة بدل العربية
viewport    → الشرط الأول ليظهر الموقع صحيحاً على الجوال
خطأ شائع: نسيان سطر viewport يجعل الجوال يتعامل مع صفحتك كصفحة سطح مكتب مصغّرة، فتصبح النصوص صغيرة والتمرير أفقياً. إذا ظهر موقعك «مضغوطاً» على جوالك، ابحث عن هذا السطر أولاً.

3. العناصر الدلالية: اكتب بنية يفهمها الإنسان

يمكنك بناء صفحة كاملة بعناصر div فقط، لكن ذلك يجعل الكود بلا معنى. استخدم العنصر الذي يصف وظيفته:

<header>   رأس الصفحة: الشعار والقائمة
<nav>      روابط التنقل
<main>     المحتوى الأساسي (واحد فقط في الصفحة)
<section>  قسم مستقل بعنوان
<article>  محتوى مكتمل بذاته: مقال، بطاقة، تعليق
<aside>    محتوى جانبي: فهرس، إعلان
<footer>   تذييل الصفحة

الفائدة ليست جمالية فقط. قارئ الشاشة للمكفوفين يستخدم هذه العناصر للتنقل، ومحركات البحث تفهم ترتيب الأهمية منها.

وهذه العناصر التي ستستخدمها في كل صفحة تقريباً:

<h1>عنوان رئيسي</h1>          مرة واحدة لكل صفحة
<h2>قسم</h2>                   ثم h3 للتفريعات
<p>فقرة نصية</p>
<a href="page.html">رابط</a>
<img src="photo.jpg" alt="وصف الصورة">
<ul><li>عنصر في قائمة</li></ul>
<strong>نص مهم</strong>

الخاصية alt في الصور ليست تجميلية: هي النص البديل الذي يقرأه قارئ الشاشة، ويظهر عند فشل تحميل الصورة. اكتب فيها وصفاً حقيقياً دائماً.

4. CSS: أول قاعدة

قاعدة CSS بسيطة التركيب: محدِّد + خصائص وقيم.

h1 {
  color: #1a1a1a;
  font-size: 2rem;
  margin-bottom: 16px;
}

ثلاث طرق للوصول إلى عنصر:

p { }            /* كل عناصر p */
.card { }        /* كل عنصر class="card" */
#main { }        /* العنصر ذو id="main" */

/* الأكثر استخداماً: كلاس على عنصر */
<div class="card">...</div>

القاعدة العملية: استخدم الكلاسات دائماً. الـ id يجب أن يكون فريداً في الصفحة، ويُستخدم للربط الداخلي (href="#main") لا للتنسيق.

5. نموذج الصندوق — أهم مفهوم في CSS

كل عنصر في الصفحة هو صندوق مستطيل، وله أربع طبقات من الداخل إلى الخارج:

المحتوى (content)
  ↓ الحشوة (padding)   ← مسافة داخلية
  ↓ الحد (border)
  ↓ الهامش (margin)    ← مسافة خارجية

.card {
  padding: 24px;        /* مسافة داخل الصندوق */
  border: 1px solid #ddd;
  margin-bottom: 20px;  /* مسافة بين هذا الصندوق والذي بعده */
}
افهم الفرق مرة واحدة: padding مسافة داخل الحد، وخلفيتها تتلوّن مع الصندوق. margin مسافة خارج الحد، لا تتلوّن أبداً.

ولتجنب أكثر مشكلة تؤرّق المبتدئين (عنصر أعرض من الشاشة بسبب الحشوة)، أضف هذه القاعدة في أعلى ملف CSS:

*, *::before, *::after {
  box-sizing: border-box;
}

هذه القاعدة تجعل width: 100% يعني العرض الكامل بما فيه الحشوة والحد، لا زيادة عليها. أضفها الآن وسلّم نفسك من عشرات الساعات.

6. Flexbox: ترتيب العناصر بجانب بعضها

لترتيب عناصر أفقياً (أو عمودياً) مع تحكم كامل في المسافات، Flexbox هو أسرع طريق:

.row {
  display: flex;
  gap: 16px;              /* المسافة بين العناصر */
  align-items: center;    /* محاذاة رأسية في الوسط */
  justify-content: space-between; /* توزيع أفقي */
}

وHTML بسيط يوضح الفكرة — شريط علوي كلاسيكي:

<header class="row">
  <strong>شعاري</strong>
  <nav class="row">
    <a href="#">الرئيسية</a>
    <a href="#">المقالات</a>
  </nav>
</header>

ثلاث خصائص تحلّ 90% من الحالات:

الخاصيةماذا تفعل
gapمسافة موحّدة بين العناصر — أفضل من margin هنا
align-itemsمحاذاة رأسية: center / flex-start
justify-contentتوزيع أفقي: space-between / center

7. تصميم متجاوب بلا تعقيد

درس واحد يغيّر كل شيء: لا تصمّم للجوال بشكل منفصل. صمّم للحاسوب، ثم أضف قاعدة تُعدّل ما ينكسر على الشاشات الصغيرة:

/* التنسيق الأساسي: للحاسوب */
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}

/* إذا كان العرض أقل من 640px */
@media (max-width: 640px) {
  .cards {
    grid-template-columns: 1fr;   /* عمود واحد على الجوال */
  }
}

نقطتان عمليتان تكفيانك في البداية:

@media (max-width: 860px) { /* أجهزة لوحية */ }
@media (max-width: 640px) { /* جوال */ }

وللنصوص، استخدم clamp() بدل حجم ثابت ليقيس المتصفح الحجم المناسب تلقائياً:

h1 {
  font-size: clamp(1.9rem, 5vw, 3.4rem);
  /* الحد الأدنى — الحجم المفضّل — الحد الأعلى */
}

8. المشروع: صفحة شخصية كاملة

اجمع كل ما سبق في ملف واحد. انسخ هذا الكود وشغّله، ثم عدّل الأسماء والألوان:

<!DOCTYPE html>
<html lang="ar" dir="rtl">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>صفحتي الشخصية</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>

  <header class="bar">
    <strong>اسمي</strong>
    <nav><a href="#about">عني</a></nav>
  </header>

  <main>
    <section id="about" class="hero">
      <h1>مرحباً، أنا مطوّر</h1>
      <p>أتعلم البرمجة وأبني مشاريع صغيرة كل أسبوع.</p>
      <a class="btn" href="#">تواصل معي</a>
    </section>

    <section class="cards">
      <article class="card"><h2>مهارة أولى</h2><p>وصف قصير.</p></article>
      <article class="card"><h2>مهارة ثانية</h2><p>وصف قصير.</p></article>
      <article class="card"><h2>مهارة ثالثة</h2><p>وصف قصير.</p></article>
    </section>
  </main>

  <footer class="bar"><small>© 2025</small></footer>

</body>
</html>

وملف style.css المقابل:

*, *::before, *::after { box-sizing: border-box; }

body {
  margin: 0;
  font-family: system-ui, sans-serif;
  line-height: 1.8;
  background: #0b0d17;
  color: #eef1f8;
}

.bar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  gap: 16px;
  padding: 18px 24px;
  border-bottom: 1px solid rgba(255,255,255,.1);
}
.bar nav { display: flex; gap: 16px; }
.bar a { color: #00d4ff; text-decoration: none; }

.hero { padding: 72px 24px; text-align: center; }
.hero h1 { font-size: clamp(1.8rem, 5vw, 3rem); margin: 0 0 14px; }
.hero p { color: #a7b0c4; margin-bottom: 26px; }

.btn {
  display: inline-block;
  padding: 13px 28px;
  border-radius: 99px;
  background: linear-gradient(135deg, #6d5efc, #00d4ff);
  color: #fff;
  font-weight: 700;
  text-decoration: none;
}

.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
  padding: 0 24px 72px;
  max-width: 1100px;
  margin-inline: auto;
}
.card {
  padding: 24px;
  border-radius: 16px;
  border: 1px solid rgba(255,255,255,.1);
  background: rgba(255,255,255,.04);
}
.card h2 { font-size: 1.1rem; margin-top: 0; }

@media (max-width: 640px) {
  .cards { grid-template-columns: 1fr; }
  .hero { padding: 48px 20px; }
}

افتح index.html في المتصفح، ثم صغّر نافذة المتصفح بيدك حتى ترى التصميم يتحول إلى عمود واحد. هذا هو التصميم المتجاوب يعمل أمامك.

9. كيف تتحقق من عملك

قبل أن تنتقل لأي درس آخر، تدرّب على هذه الفحوصات الثلاث:

1. اضغط F12 → تبويب Console
   يجب ألا ترى أخطاء حمراء.

2. في أدوات المطوّر، جرّب وضع الجهاز (Ctrl+Shift+M)
   واختبر عرض 360px و 768px.

3. في تبويب Elements، مرّر على عناصرك
   وتأكد أن كل صندوق في مكانه المنطقي.
الخطوة التالية: لا تنتقل إلى JavaScript قبل أن تبني صفحتين كاملتين بنفسك دون نسخ. خذ صفحة المشروع أعلاه وأعد بناءها من الذاكرة، ثم غيّر الألوان والترتيب. التكرار هو ما يثبّت الأساس.
