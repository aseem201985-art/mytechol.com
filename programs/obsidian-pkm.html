Obsidian: ابنِ «دماغاً ثانياً» عربياً يربط معرفتك بدل أن يدفنها

ملاحظات كثيرة بلا نظام تعني معرفة صفر. طريقة عمل كاملة: بنية مجلدات، وسوم، ملاحظات ذرّية، مراجعة أسبوعية، ونسخ احتياطي — بالعربية ودعم RTL.

كلنا نكتب ملاحظات. القليل منّا يستطيع استرجاعها عند الحاجة. السبب ليس الذاكرة، بل غياب بنية تسمح للمعلومة الجديدة بالاتصال بالقديمة.

الإعداد العربي الصحيح

  1. الإصدار: نزّل آخر نسخة من obsidian.md — مجاني للاستخدام الشخصي.
  2. الخط: الإعدادات ← المظهر ← الخط → اختر خطاً عربياً جيداً (Cairo, IBM Plex Sans Arabic).
  3. RTL: فعّل إضافة RTL Support من الإضافات المجتمعية لضبط اتجاه المحرّر.
  4. المحرّر: فعّل Live Preview لترى التنسيق أثناء الكتابة.
  5. المظهر: جرّب ثيم Minimal — نظيف ويحترم العربية.
نصيحة تقنية: أبقِ الحفظ التلقائي مفعّلاً (افتراضي) واحفظ المستودع في مجلد تزامن (OneDrive / iCloud / Syncthing) بدل الاعتماد على المزامنة المدفوعة.

الأرقام في البداية تُثبّت الترتيب، وهذا يمنع إعادة تنظيم لا نهائية.

الملاحظات الذرّية: الوحدة الأساسية

ملاحظة واحدة = فكرة واحدة. العنوان جملة كاملة، والمحتوى 3–7 أسطر.

{{
atomic-note.md
# الفرق بين الحمل والتزامن لا يُعنى بالسرعة

السرعة المشتركة شيء، والتصميم المشترك شيء آخر.

الحمل: عدد الطلبات في نفس اللحظة.
التزامن: عدد الطلبات التي تُعالَج فعلاً في نفس اللحظة.

#أداء #أنظمة #مفاهيم

المصدر: [[ملخّص كتاب Designing Data-Intensive Applications]]
يرتبط بـ: [[قائمة انتظار الرسائل]] · [[حدّ التزامن]]
}}

لاحظ البنية: فكرة + تعريفات + وسوم + روابط + مصدر. كل ملاحظة تحمل هذا الهيكل تصبح قابلة للبحث والربط وإعادة الاستخدام.

الفرق التقني: الملاحظات تكبر وتصبح مجموعة (Graph)، والوسوم تُستخدم للبحث والفلترة. لا تستخدم وسماً حيث تحتاج رابطاً، ولا رابطاً حيث يكفي وسم.

المراجعة الأسبوعية: 20 دقيقة تُنقذ النظام

  1. أفرغ الـ Inbox — كل ملاحظة إمّا تُحوَّل للأرشيف أو تُحوَّل لملاحظة ذرّية.
  2. اربط الجديد — كل ملاحظة تحتاج رابطاً واحداً على الأقل.
  3. راجع المشاريع — هل هناك مشروع توقّف؟ انقله للأرشيف بشفافية.
  4. اقرأ ملاحظة قديمة — ابحث عن كلمة عشوائية، واقرأ أول نتيجة.
المراجعة هي ما يفرّق بين «مقبرة ملاحظات» و«دماغ ثانٍ». بدونها، كل النظام يتحوّل إلى أرشيف أنيق لا تقرأه.

النسخ الاحتياطي: انسَ المزامنة، فكّر بالنسخة

المزامنة ليست نسخاً احتياطياً — لو حُذف ملف عن طريق الخطأ، فسيُحذف في كل الأجهزة.

{{
backup.sh
# نسخة أسبوعية مضغوطة مؤرّخة
cd ~/Documents && tar -czf "vault-$(date +%F).tar.gz" vault/

# احتفظ بآخر 8 نسخ فقط
ls -1t vault-*.tar.gz | tail -n +9 | xargs -r rm --

# الأفضل: نسخة خارج الجهاز (Git للمستودعات النصية)
cd ~/Documents/vault
git add -A && git commit -m "weekly snapshot $(date +%F)"
git push
}}
