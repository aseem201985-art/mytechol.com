تشغيل نماذج LLM في الإنتاج: التكلفة، الكمون، والموثوقية

ما ينجح في العرض التوضيحي يفشل تحت الحمل. دليل هندسي: التخزين المؤقت، البثّ، التوجيه بين النماذج، احتواء الأخطاء، ومراقبة ما يفعله نموذجك فعلاً.

LLM

تحويل نموذج لغوي من تجربة إلى منتج يواجه ثلاث جدران حقيقية: الفاتورة، الكمون، والثقة. هذه المقالة تعالج الثلاثة بأمثلة كود قابلة للتطبيق اليوم.

كيف تُحسب التكلفة فعلاً

الفاتورة = (رموز الإدخال × سعر الإدخال) + (رموز الإخراج × سعر الإخراج). المفاجأة أن الإخراج أغلى بثلاثة إلى أربعة أضعاف، والسياق الطويل يُعاد دفعه في كل طلب.

المصدرالسببالتخفيض النموذجي
سياق متضخّمإعادة إرسال نفس التعليمات كل مرة30–50%
بدون تخزين مؤقتطلبات متكررة تُعيد الحساب20–40%
نموذج أكبر من اللازممهام بسيطة على نموذج ضخم50–80%
إخراج مطوّل بلا داعٍغياب حدّ أقصى للرموز15–25%

التخزين المؤقت الذكي

ثلاث طبقات تُطبَّق بالترتيب من الأرخص إلى الأغلى:

{{
cache.py
import hashlib, json

def make_key(model: str, messages: list, temperature: float) -> str:
    # مفتاح دقيق يتضمن كل ما يؤثر في الناتج.
    payload = json.dumps(
        {{"m": model, "t": temperature,
         "msg": [(m["role"], m["content"]) for m in messages]}},
        ensure_ascii=False, sort_keys=True
    )
    return "llm:" + hashlib.sha256(payload.encode()).hexdigest()[:32]

async def cached_completion(model, messages, temperature=0.2, ttl=3600):
    key = make_key(model, messages, temperature)
    if (hit := await redis.get(key)):
        return json.loads(hit)                    # طبقة 1: نتيجة مطابقة

    resp = await client.chat.completions.create(
        model=model, messages=messages,
        temperature=temperature, max_tokens=800   # سقف يمنع الإطالة
    )
    await redis.setex(key, ttl, json.dumps(resp.model_dump()))
    return resp.model_dump()
}}
لا تخزّن مؤقتاً عندما تكون temperature > 0 وتحتاج تنويعاً — أو اجعل الـ TTL قصيراً جداً. المفتاح يجب أن يتضمن درجة الحرارة وإصدار تعليمات النظام، وإلا حصلت على نتائج قديمة تُربك المستخدم.

البثّ: الكمون المدرك للمستخدم

الكمون الفعلي لم ينقص، لكن الكمون المُدرَك ينخفض 5–8 أضعاف لأن المستخدم يرى الحروف تتوالى. مع البثّ، اعرض التوكن الأول في أقل من 500ms.

{{
stream.py
from fastapi import FastAPI
from fastapi.responses import StreamingResponse

app = FastAPI()

@app.post("/chat")
async def chat(body: ChatIn):
    async def gen():
        stream = await client.chat.completions.create(
            model="gpt-4o-mini", messages=body.messages,
            stream=True, max_tokens=600
        )
        async for chunk in stream:
            if (t := chunk.choices[0].delta.content):
                yield f"data: {{json.dumps({{'d': t}}, ensure_ascii=False)}}\\n\\n"
        yield "data: [DONE]\\n\\n"

    return StreamingResponse(gen(), media_type="text/event-stream")
}}

إسقاط العميل ليس إلغاءً للفاتورة. إذا أغلق المستخدم الصفحة، توقف أنت عن السحب عبر:

توجيه النماذج: أرخص نموذج يكفي

معظم الطلبات بسيطة. صنّف أولاً ثم وجّه:

{{
router.py
RULES = {{
    "classify": "gpt-4o-mini",     # تصنيف واستخراج
    "summarize": "gpt-4o-mini",
    "reason": "gpt-4o",            # استدلال معقّد
    "code": "claude-sonnet",       # كتابة كود
}}

def pick_model(task: str, tokens: int) -> str:
    if tokens > 60_000:            # سياق ضخم -> نموذج طويل المدى
        return "gemini-flash"
    return RULES.get(task, "gpt-4o-mini")
}}
ابدأ بأصغر نموذج ممكن، وارفع المستوى فقط عندما يفشل في تقييمك. الفرق في التكلفة بين نموذج صغير وكبير قد يبلغ 20 ضعفاً مقابل 3–5% فرق في الجودة على المهام البسيطة.

الموثوقية: افترض أن كل شيء سيفشل

{{
resilience.py
import asyncio, random

async def resilient_call(fn, *, retries=3, base=0.6):
    for attempt in range(retries):
        try:
            return await asyncio.wait_for(fn(), timeout=25)
        except (TimeoutError, RateLimitError) as e:
            if attempt == retries - 1:
                raise
            # انحدار أسّي مع jitter — يمنع موجات إعادة محاولة متزامنة
            delay = base * (2 ** attempt) + random.uniform(0, 0.4)
            await asyncio.sleep(delay)
}}
  1. مزوّدان على الأقل — واجهة موحّدة تسمح بالتبديل عند سقوط أحدهما.
  2. قاطع دائرة (Circuit Breaker): بعد 5 أخطاء متتالية، توقّف 30 ثانية.
  3. مهلة إلزامية في كل استدعاء — بلا استثناء.
  4. مسار احتياطي ثابت: ردّ مُعد مسبقاً أفضل من شاشة خطأ.
  5. تحقّق من المخرجات: JSON غير صالح أو حقول ناقصة يجب ألا تصل للمستخدم.

المراقبة: ماذا تفعل نماذجك فعلاً؟

سجّل لكل طلب: النموذج، عدد رموز الإدخال والإخراج، الكمون، التكلفة، وهل نجح التحقق.

def log_call(model, usage, latency_ms, ok: bool):
    metrics.histogram("llm.latency", latency_ms, tags={{"model": model}})
    metrics.increment("llm.tokens.input", usage.prompt_tokens)
    metrics.increment("llm.tokens.output", usage.completion_tokens)
    metrics.increment("llm.cost_usd", estimate_cost(model, usage))
    if not ok:
